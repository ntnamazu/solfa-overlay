# 要求内容

- 対象 Issue: [#4 Phase 6: Editor に元PDF＋階名注釈の楽譜プレビューを表示する](https://github.com/ntnamazu/solfa-overlay/issues/4)
- 親 Issue: #14（Phase 6）。後続の #5（注釈の手動編集・F-5）/ #6（転調点の指定・F-6）は本作業に blocked by

## 概要

Editor 画面に、元PDFのページと階名注釈を重ねて表示する楽譜プレビュー（読み取り専用）を追加する。

## 背景

現在の Editor は、階名をパート×小節のテキスト一覧（曲の先頭 24 小節まで）で確認する形式にとどまる
（`docs/functional-design.md`「Editor画面の表示」の Phase 5 時点の実装）。
出力PDFを書き出して開くまで、階名が楽譜のどこにどう載るかを確認できない。

発案者自身が実利用の中で「このUIがないと使いにくい」と判断し、PRD のセカンダリーKPI
「発案者自身の実利用（手書きに戻らないこと）」に直結するため、フィードバックを待たずに優先度を上げた
（判断の記録は #4 本文）。

## 実装対象の機能

### 1. 元PDFのページ描画

- PDF.js で元PDFの全ページを Editor 内に縦に並べて描画する
- 表示中のページ付近だけをキャンバスに描く（遅延描画。アーキテクチャ設計書「表示中ページ±1のみレンダリング」）
- 元PDFを読めない場合は理由を表示し、画面の他の部分（一覧・出力）は使えるままにする

### 2. 階名注釈のオーバーレイ

- 注釈を出力PDFと同じ位置（同じアンカー・同じ座標変換）に重ねて表示する
- 幹音=濃赤・変化音=紫＋太字。色・書体・文字サイズは設定値（`ProjectSettings`）に従う
- 削除フラグの立った注釈・孤立注釈は出力PDFと同じく表示しない
- 標準フォントで描けない文字の置換（`♯`→`#` 等）も出力PDFと揃える

### 3. スキップ小節のハイライトとジャンプ

- スキップ小節を楽譜上に黄色の矩形でハイライトする（出力PDFには含めない）
- 「階名が付かなかった小節」の一覧の各行をクリックすると、該当箇所までスクロールして強調する

### 4. 配置警告の位置表示

- 衝突回避に失敗した注釈（`placementUnresolved`）の位置に警告マーカーを表示する

## 受け入れ条件

### 元PDFのページ描画

- [ ] 取り込んだ楽譜の全ページが Editor 上に並ぶ（Victoria のように 1 つの元PDFページに複数の Audiveris ページが対応する場合も、ページが重複・欠落しない）
- [ ] キャンバス描画は表示中のページ付近に限られる
- [ ] 元PDFを読み込めないときは、理由を示すメッセージが出て、PDF出力などの他の操作は妨げない
- [ ] CSP（`default-src 'self'`）を緩めずに PDF.js が動く（`index.html` を変更しない。worker・デコーダは同一オリジンから配る）

### 階名注釈のオーバーレイ

- [ ] 注釈の表示位置が OverlayRenderer と同じ変換（`.omr` px → pt、軸ごとの縮尺、ページ対応）から求まる
- [ ] 表示される注釈の件数が出力PDFの描画件数と一致する（実データ Victoria / divisi で固定）
- [ ] 変化音は色と太字の両方で区別され、色は設定値に従う

### スキップ小節

- [ ] スキップ小節の位置（小節の横範囲×パートの譜表の縦範囲）が黄色でハイライトされる
- [ ] 一覧の行をクリックすると、該当のハイライトまでスクロールし、強調表示される
- [ ] 位置を特定できない小節は、一覧にクリックできない行として残る（無言で消さない）

### 配置警告

- [ ] `placementUnresolved` の注釈の位置に警告マーカーが出る

### 性能

- [ ] divisi（3,500 注釈・20 ページ）でプレビューデータの構築が 1 秒未満で終わる
- [ ] 画面に描く注釈は表示中のページ付近に限られ、5,000 音規模でも DOM 要素数が全音符数に比例しない

## 成功指標

- 出力PDFを書き出さなくても、階名の位置・スキップ小節・配置警告を Editor 上で確認できる
- PRD 非機能要件「確認・修正UIの操作 1 秒以内」を満たす構造（遅延描画・Main 側でのデータ確定）になっている

## スコープ外

以下はこのフェーズでは実装しません:

- 注釈の追加・編集・削除（#5 / F-5）
- 転調点マーカーの表示と転調点の指定（#6 / F-6）
- 拡大縮小などの表示倍率の操作
- StructureConfirm 画面のページサムネイル・構造オーバーレイ
- 埋め込みフォントによる `♯` `♭` の字形描画（出力PDF側の将来課題と揃える）
