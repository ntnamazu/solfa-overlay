### 実装完了日

### 計画と実績の差分

**計画と異なった点**:

- **誤記の分布が想定より広かった**。計画では `tests/fixtures/victoria/README.md` の1箇所を直す想定だったが、
  リポジトリ全体を `grep` したところ **`docs/functional-design.md`・`docs/architecture.md`・
  `docs/ideas/solfa-annotation-app.md` の計3箇所**にも「パブリックドメイン」と書かれていた。
  とくに `solfa-annotation-app.md`（プロトタイプ検証メモ）は**最初期の記録**であり、
  ここでの誤認がその後のドキュメントへ順に伝播したとみられる。**誤った事実は、それが最初に書かれた
  場所から下流のドキュメントへ複製されていく**ことを実例として確認した。

**新たに必要になったタスク**:

- **リポジトリ全体への `grep` 掃討**。「Victoria」「19716」「magnum」と「PD / パブリックドメイン」の
  積で検索し、取りこぼしを機械的に洗い出した。1箇所を直して終わりにしていたら、
  設計書に誤った記述が残り続けていた。

### 学んだこと

**技術的な学び**:

- **楽曲のパブリックドメインと、楽譜（版）のライセンスは別物**。古典派以前の作曲家の作品でも、
  近年に浄書・校訂された版には編集者の権利や CC ライセンスが付く。IMSLP は**ファイル単位**で
  ライセンスを表示するため、「作曲者が何年に亡くなったか」だけで判断すると誤る。
  今回の Victoria（1611年没）は、その典型的な落とし穴だった。
- **CC の ShareAlike は GPL のような強い伝播をしない**。SA が及ぶのは「その派生物」であり、
  同じリポジトリに置いた無関係なコードまで汚染するわけではない。したがってアプリ本体の MIT は
  無傷のまま、**問題のある成果物（翻案 PDF）だけを取り除けば整合が取れる**と判断できた。
- **NC（非営利）条項はコードのライセンスと衝突しうる**。MIT は商用利用を許可する宣言であり、
  そこに NC 素材が混ざると再利用者に矛盾したシグナルを送る。**素材を消すのではなく、
  どこに NC が及ぶのかを明示する**ことで、矛盾ではなく「区別」として扱えるようにした。
- **`git rm --cached` は追跡だけを外し、ワーキングツリーの実体を残す**。手元の検証環境を壊さずに
  リポジトリからだけ取り除ける。実行後に `ls` で実体の残存を確認する手順を入れておくと安全。

**プロセス上の改善点**:

- **公開直前の再確認が効いた**。ユーザーが IMSLP のページを見直したことで、公開後に発覚していたら
  対応コストが跳ね上がっていた問題（第三者著作物の帰属表示漏れ）を、公開前に処理できた。
  **「PD だと思っていた素材を、公開前にもう一度確認する」は、リリース前チェックリストに値する。**
- **既存の steering を再オープンせず、新しい steering を切った**判断が良かった。
  前タスク（`20260726-v0.1.0-public-release-prep`）は振り返りまで書いて完了していたため、
  そこへ追記すると「完了」の意味が壊れる。ライセンスコンプライアンスという独立した主題として
  記録を分けたことで、後から経緯を辿りやすくなった。
- **ネットワーク制限に阻まれたとき、ユーザーへホワイトリスト追加を依頼した**のが有効だった。
  帰属表示は「誰の何を」が正確でなければ意味をなさないため、推測で書かずに一次情報を取りに行けた。
  実際、最初の抽出ではライセンスを 4.0 と誤読しており、**同じページを別の切り口で再取得して
  照合したことで 3.0 と確定**できた（ユーザーの当初報告が正しかった）。

### 次回への改善提案

- **素材を採用する時点で帰属表示を書く運用にする**。今回は採用から数か月後に誤りが発覚した。
  `docs/development-guidelines.md` を更新して「帰属表示を README に書くこと」を必須条件にしたので、
  次回以降はフィクスチャ追加とセットで記録される。
- **一次情報の URL を必ず記録する**。今回 divisi のファイル番号（#175782）が IMSLP 上で
  #954369 に置き換わっていた。**IMSLP はファイルを差し替えることがある**ため、
  ファイル番号ではなく**ページ URL を正**として記録するようフィクスチャ README を修正した。
- **商用展開を検討する段階になったら、Victoria フィクスチャを PD 版へ差し替える**。
  候補（Proske 1854 / Pedrell 1902）は `tests/fixtures/victoria/README.md` に記録済み。
  ただし回帰値の全面再測定が必要なため、必要になるまで着手しない。
