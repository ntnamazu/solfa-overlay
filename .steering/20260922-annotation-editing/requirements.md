# 要求内容

- 対象 Issue: [#5 Phase 6: 楽譜プレビュー上で階名注釈を追加・編集・削除できるようにする（F-5）](https://github.com/ntnamazu/solfa-overlay/issues/5)
- ついでに対応: [#17 Editor: 楽譜プレビューを画面の最後に移し、一覧と出力ボタンを上に置く](https://github.com/ntnamazu/solfa-overlay/issues/17)
- 親 Issue: #14（Phase 6）。前提の #4（楽譜プレビュー）は完了済み

## 概要

Editor の楽譜プレビュー上で、階名注釈を追加・書き換え・削除できるようにする（PRD F-5 / P0）。
あわせて、楽譜プレビュー区画を Editor の最後へ移し、スキップ小節の一覧と PDF 出力を上に置く（#17）。

## 背景

- OMR の局所的な誤りで階名が欠落した小節（スキップ小節）は、現状ではアプリ内で埋める手段がない
- PRD の KPI「確認・修正フロー通過後の階名付与率 98%以上」「確認・修正込みで 15 分以内」は、この機能がないと達成を確認できない
- #4 の実機確認で、楽譜プレビュー（全ページを縦に並べる）の下にスキップ小節の一覧と PDF 出力ボタンが埋もれることが分かった（#17）。
  #5 で Editor に操作を足す前に並びを直しておく

## 実装対象の機能

### 1. 注釈の追加（楽譜上の任意の位置）

- 楽譜プレビューで「階名を直す」操作を有効にし、楽譜上の任意の位置を押すと、その位置に階名を書き足せる
- 押した位置が文字の左端・ベースライン（`Annotation.anchor` の基準）になる
- 追加した注釈は `origin: 'manual'` として注釈レイヤーに入る

### 2. 注釈の書き換え・削除

- 楽譜上の注釈（自動・手動とも）を押すと、文字を書き換える／削除する操作が出る
- 自動注釈の書き換えは「手動上書き文字列（`Annotation.text`）」として保持する。上書きを取り消して元の階名に戻せる
- 自動注釈の削除は `deleted` フラグを立てる（再生成で復活させない）。手動注釈の削除は実体を消す
- 削除した自動注釈は Editor の一覧から元に戻せる（誤操作の救済。削除すると楽譜上から消えて押せなくなるため）

### 3. 出力PDF・保存・再計算への反映

- 修正結果が出力PDFに反映される（OverlayRenderer は注釈レイヤーをそのまま描く）
- 修正は自動保存の対象になり、プロジェクトファイルを開き直すと復元される
- 訂正・表記の切り替えで再計算しても、手動注釈・削除フラグ・手動上書きが保全される

### 4. Editor の区画の並び替え（#17）

- 楽譜プレビュー区画を Editor の最後に移す（スキップ小節の一覧・警告・PDF出力をプレビューより上へ）
- 階名の表記の切り替えは、切り替え結果がすぐ下で見えるよう楽譜プレビューの直前に置いたままにする

## 受け入れ条件

### Issue #5（PRD F-5）

- [x] 音符数不一致等でスキップされた小節が一覧で提示され、該当箇所へジャンプできる（#4 で実装済み。並び替え後も動くこと）
- [x] 楽譜画像上の任意の位置に階名注釈を追加・編集・削除できる
- [x] 修正結果が出力PDFに反映される
- [x] 修正状態（注釈レイヤーの中間データ）をファイルとして保存・再読み込みできる
- [x] 再計算後も手動注釈（`origin: 'manual'`）と削除フラグが保全される

### 追加の条件（本作業で定める）

- [x] 押した位置と、追加された注釈が画面・出力PDFに描かれる位置が一致する（座標の往復変換が OverlayRenderer と同じ縮尺）
- [x] 1 つの元PDFページに複数の Audiveris ページが対応する場合（Victoria）も、押した位置のページに追加される
- [x] 削除した自動注釈を元に戻せる
- [x] 注釈の編集では承認（`completedAt`）を無効化しない（設定変更と同じく「何を確認したか」を変えないため）
- [x] 不正な入力（空文字・存在しない注釈・変換できないページ・有限でない座標）は Main 側で拒否する

### Issue #17

- [x] 楽譜プレビュー区画が Editor の最後の区画になる
- [x] 区画の並び順のテストを更新する

## 成功指標

- スキップ小節の一覧から該当箇所へジャンプし、その場で欠けた階名を書き足して、出力PDFに反映できる
- 注釈の編集 1 回の応答が PRD 非機能要件「確認・修正UIの操作 1 秒以内」に収まる（解析は 1 曲数百 ms。#4 と同じ流し直し方式）

## スコープ外

以下はこのフェーズでは実装しません:

- 注釈のドラッグによる移動（位置を変えたい場合は削除して追加し直す）
- 手動注釈を変化音（紫・太字）として描く指定（手動注釈は常に幹音の色で描く。音符に紐付かないため変化の有無が決まらない）
- 取り消し（Undo / Redo）の汎用機構（削除の取り消しのみ、一覧から行える）
- #8（「適用されなかった訂正」の内部識別子の表示）。IPC 契約の変更を伴う別件のため、ついでの対象はユーザー指定の #17 に限る
- 転調点の指定（#6 / F-6）、表示倍率の操作
