# 要求内容

## 概要

Editor の楽譜プレビュー上で、任意の小節を転調点として指定し、そこから先の解釈先の調（主音・長/短）を設定できるようにする（PRD F-6 / P1・Issue #6）。
自動検出した調の区切り（調号の変化点）も同じ UI に表示し、編集・削除できるようにする。

## 背景

- 調号が変わらない一時転調や、歌い手の解釈に沿った読み替えは、現状では反映できない
- 自動検出した調号変更点を画面上で確認・修正する手段がない（ClefKeyConfirm の表は旋法の指定しかできず、区切りの追加・削除はできない）
- `KeyRegionBuilder` は「区間の新規挿入は F-6 の担当」として既存区間の訂正しか行っていない

## 実装対象の機能

### 1. 転調点の指定（新規挿入）

- 楽譜プレビューで小節の中を押すと、編集パネルに「N 小節目から転調」が出る
- 押すと転調点パネルが開き、解釈先の調（30 調: 長調 15・短調 15）を選んで適用できる。初期値はその小節で有効な調
- 適用すると `source: 'user'` の KeyRegion が挿入され、階名が再計算・再描画される

### 2. 転調点マーカーの表示と編集・削除

- KeyRegion の境界（曲頭を含む）を、楽譜上の小節の左端にマーカーで表示する（auto=グレー、user=青）
- マーカーを押すと転調点パネルが開き、調の選び直し・削除ができる（曲頭は削除できない）
- auto のマーカーを編集すると user として上書きされる
- Editor に「調の区切り」の一覧も置き、マーカーと同じパネルを開けるようにする（楽譜上の位置が取れない区切り・キーボード操作の代わり）

### 3. 保存と再出力時の維持

- 転調点の指定はプロジェクトファイルへ保存され、再読み込み・再解析・PDF出力でも維持される
- 再計算後も手動注釈・削除フラグは保全される

## 受け入れ条件

### 転調点の指定

- [ ] 楽譜上の任意の小節を転調点として指定し、以降（次の転調点まで）の解釈先の調を設定できる
- [ ] 指定に応じて該当範囲の階名が再計算される（範囲外の階名は変わらない）

### 自動検出の区切りの表示・修正

- [ ] 自動検出された調号変更点も同じ UI 上に表示され、上書き修正（user になる）・削除できる
- [ ] 曲頭の調は選び直せるが削除できない

### 永続化

- [ ] 転調点の指定は保存され、再読み込み後・PDF出力時にも維持される
- [ ] 旧版（schemaVersion 1）のプロジェクトファイルを開ける（マイグレーション）
- [ ] 再計算後も手動注釈・削除フラグが保全される

## 成功指標

- 実フィクスチャ（Victoria）で転調点を挿入すると、その小節から次の区切りまでの階名だけが変わる
- 指定 → 保存 → 再読み込み → 出力で結果が一致する

## スコープ外

以下はこのフェーズでは実装しません:

- **小節の途中（拍位置）からの転調**: `NoteEvent` が小節内オフセットを持たず、パートごとに `divisions` が異なるため
  オフセットの単位をそろえる設計（ScoreModel のスキーマ変更）が要る。小節単位で指定し、`ScorePosition.offset` は 0 とする。
  既知の限界として機能設計書に記録する
- 「指定範囲」（終わりの位置を指定する転調）: 次の転調点を置くことで同じ結果になるため、終点の指定 UI は設けない
- 影響範囲に限定した差分再計算: 既存方針（編集のたびに解析を頭から流し直す。1 曲数百 ms）に合わせる
